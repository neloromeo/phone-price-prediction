# Phone Price Prediction

## Project Overview
This machine learning project predicts smartphone prices using different regression algorithms.

## Objectives
- Clean the dataset
- Detect and handle outliers
- Perform exploratory data analysis (EDA)
- Train machine learning models
- Evaluate model performance

## Algorithms Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Evaluation Metrics
- MAE
- RMSE
- R² Score

## Project Workflow
1. Data Cleaning
2. Outlier Detection
3. EDA
4. Feature Selection
5. Model Training
6. Model Evaluation

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
